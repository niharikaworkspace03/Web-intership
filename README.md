# HTML Internship Project

## Description
This project was developed as part of an HTML internship to demonstrate the fundamentals of web development using HTML5. It includes a personal one-page website with navigation links, a student details table, a store webpage, and a registration form with various input fields. The project showcases the use of semantic HTML elements, hyperlinks, tables, forms, and clean, well-structured webpage design.

## Features
- Personal one-page website
- Navigation links between web pages
- Student details table
- Store webpage
- Registration form with input fields
- Semantic HTML5 structure

## Technologies Used
- HTML5
